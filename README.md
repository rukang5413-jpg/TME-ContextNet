# TME-ContextNet

**TME-ContextNet: Class-Conditioned Spatial Supervision and Grouped Decoding for Joint Nuclei Instance Segmentation and Classification**

This repository is the project page for TME-ContextNet.

## Release status

- **Paper:** The arXiv preprint is being prepared. Its link will be added here once available.
- **Public companion code:** Not released yet. Configuration, data-processing, post-processing, and evaluation utilities are planned for release after the arXiv preprint is announced.
- **Restricted core:** Selected core implementations, including CSS target construction, LGCM, GTD, and complete network assembly, will not be included in the public companion-code edition due to patent-related restrictions.

This placeholder repository currently contains documentation only. It does not include model implementations, pretrained weights, or datasets. The planned public edition will not independently train or run the complete TME-ContextNet model.
